# Amirhossein Eskorouchi - Professional Website

Source repository for the professional research and engineering portfolio of
Amirhossein Eskorouchi.

The website will connect research projects, publications, software, datasets,
posters, presentations, teaching, mentoring, and professional experience.

## Local development

Run:

    npm.cmd install
    npm.cmd run dev

## Production validation

Run:

    npm.cmd run build
    npm.cmd run preview
